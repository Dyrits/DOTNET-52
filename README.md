# DOTNET-52

## About The Project

A set of small .NET projects and exercises grouped in a single solution (DOTNET-52.sln): AAA, BlazorApp, BranchesAndLoops, and NumbersInCSharp.

### Built With

- C# / .NET
- Blazor

## Getting Started

### Prerequisites

- The .NET SDK

### Running

Open `DOTNET-52.sln` in an IDE with .NET support, or run an individual project with the .NET CLI:

```sh
cd BlazorApp
dotnet run
```
